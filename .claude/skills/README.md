# Kyle & Co marketing agents

Five skills, one lane each. All draft and recommend only. Brandice gives the go for anything live.

| Skill | Owns | Runs |
|---|---|---|
| kyleco-demand-gen-agent | Strategy, KPIs, weekly priorities, briefs for the other four | Cloud routine, Monday 8:07 AM ET |
| kyleco-blog-publisher | Blog posts from Google Doc to WordPress draft | On demand (needs a finished doc) |
| kyleco-content-repurposer | Newsletter brief and LinkedIn copy from published content | On demand, before each newsletter (cap 3 sends per quarter) |
| kyleco-email-social-agent | Newsletter build in MailerLite, LinkedIn posts on the content calendar | Cloud routine "LinkedIn: weekly draft run", Monday 7:47 AM ET |
| kyleco-website-manager | Site pages, links, SEO/GEO, sitemap, forms, tracking, WordPress health | Cloud routine, Wednesday 8:00 AM ET |

Where they live: this folder is the source of truth for Claude Code and for cloud routines (they clone this repo). The same skills are also uploaded to claude.ai (Settings > Capabilities > Skills) so they work in chat. When you change a SKILL.md here, re-upload it there.

Handoffs run through the monday.com Content Calendar (board 9622147123). Every agent reads briefs from demand gen first, and ends each run with a "STATUS:" update.
